# Nalaka Rest — Villa Website

> A private 3-bedroom hillside house in the cool mountain highlands of Nuwara Eliya, Sri Lanka (1,860m above sea level).

🌐 **Live Website:** https://nalak-arest.vercel.app/

---

## 🏡 About Nalaka Rest
- **Bedrooms & Beds:** 3 private bedrooms, 4 comfortable beds (accommodates up to 6 registered guests)
- **Heating & Warmth:** Electric room heaters and 24/7 geyser hot water showers for cold highland nights
- **Kitchen & Comfort:** Fully equipped self-catering kitchen with four-burner stove, microwave, refrigerator, cookware, and dining area
- **Work & Connectivity:** High-speed fibre Wi-Fi, dedicated laptop work desk, and strong cellular reception
- **Nearby Attractions:** Horton Plains National Park (~50 min), Gregory Lake (~10 min), Pedro Tea Estate & Factory (~15 min)

---

## 🛠️ Tech Stack
- **Frontend:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom Highland Theme Tokens
- **Icons:** Lucide React
- **Booking & Inquiries:** Flatpickr Range Calendar + Direct WhatsApp / Email integration
- **Deployment:** Vercel

---

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/KaweeshDinuwan/Web-site-for-the-villa.git
   cd Web-site-for-the-villa
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
